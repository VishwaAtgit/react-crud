# Crawl README

## Chain-PRs
Chain-PRs are a method of linking multiple pull requests together to ensure that changes are reviewed and merged in a specific order. This is particularly useful when one PR depends on the changes made in another. When creating a chain of PRs, be sure to reference the dependent PRs in the description of each PR.

## Evidence in PRs
When submitting a pull request, it is important to provide evidence of the changes made. This can include links to relevant issues, screenshots of the functionality, or any other documentation that supports the changes. Clear evidence helps reviewers understand the context and purpose of the PR.

## Prompt Usage
When using prompts in this project, ensure that they are clear and concise. Provide any necessary context to help the model generate the desired output. It is also helpful to include examples of expected input and output to guide contributors in their usage of prompts.
